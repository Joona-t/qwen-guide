Why multi-step agent work compounds

If each tool call succeeds with probability p, a chain of n calls succeeds with pⁿ.

~66% succeed end to end
95% per call over 8 steps lands about 66% of the time.

A simplification. Real failures aren't independent, and a validator or retry step changes the picture. BFCL scores are a relative signal, not a per-call probability. The point holds: long unsupervised chains on a small local model fail often, so keep approval gates in the loop.
