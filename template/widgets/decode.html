Decode-speed ceiling

Every generated token reads the whole model from memory, so tokens per second ≈ memory bandwidth ÷ model size.

~18 tokens/s ceiling
120 ÷ 6.6 ≈ 18 tokens per second, before overhead.

A ceiling, not a measurement. Dense-model benchmarks on a base M4 reach roughly 77–88% of this figure, so plan for less. No direct, attributable Qwen3.5 benchmark on a base M4 16 GB had been published as of October 2026. Measure your own machine with real prompts.
