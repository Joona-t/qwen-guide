What does each quant cost and buy?

Pick a model, a quant and your hardware. File sizes are the real GGUF files (Unsloth and ggml-org repos, checked 2026-11-03). Bits per weight is size × 8 ÷ parameters, the speed ceiling is bandwidth ÷ bytes read per token, and the context is whatever memory is left ÷ the model's KV cost per token.

Fits

Estimates, not measurements. Usable memory is VRAM minus 1 GB per card, or 75% of a Mac's memory. The vision projector (0.6–0.9 GB) is not counted. KV costs come from each model's config.json: 32 KiB per token for the 9B, 64 KiB for the 27B, 24 KiB for the 122B at f16, half that at q8_0. For the MoE model the speed ceiling scales the file by 10 ÷ 125 active weights, which ignores the always-read attention layers, so treat it as rough. Two cards in layer split take turns per token, so the ceiling uses one card's bandwidth. Context is capped at the 262,144-token native window.
