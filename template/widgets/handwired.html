A program, written as weights

Left, a one-line program. Right, the same program rewritten as multiplies, adds and relu(x) = max(0, x), the operations a network layer performs. Move a and watch both compute.

Program
a = 4
result = a > 4 ? 10 : 12
Program says12
Weights + ReLU
a = 4
above4 = relu(a − 4) − relu(a − 5)
       = 0
result = above4·10 + (1 − above4)·12
Network says12
Both say 12. The constants 4, 5, 10 and 12 are the weights; nothing was trained.

A program can be written as weights. That is why a trained network can also hold one: the numbers fine-tuning nudges are the same kind of object as these constants. Exact everywhere except between 4 and 5. There the gate ramps from 0 to 1 instead of jumping, so a = 4.5 gives 11 where the program gives 10.
